NVFP4 is a memory win before it is a speed win

Four-bit floating point on Blackwell halves the weight footprint of a 70B model, but only recovers its throughput advantage above batch 8.

2.1× Memory saved vs BF16, 70B weights
0.7 pp MMLU lost measured, not claimed [3]

The sources disagree. NVIDIA reports −0.7 pp on MMLU [3]; an independent reproduction measured −2.1 pp on the same checkpoint [7]. The reproduction used a different calibration set, which plausibly accounts for the gap.
Verdict

Adopt NVFP4 when the constraint is memory and the batch is small; keep BF16 where the last point of accuracy is worth twice the VRAM.
