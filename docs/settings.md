# Settings

Generated by `mix swarm_code.settings --write` from the settings registry; do not edit.
Open them with `swarmcode settings [QUERY]` or `/settings` in a session, or change them
from scripts with `swarmcode config set KEY VALUE` (`swarmcode config help`).

Scopes: `global` (the database, shared with the desktop app), `project` (the project row),
`session` (this conversation), `cli` (`cli.json`, this terminal only), `project_file`
(`.swarm_code/config.json`, read-only here).
