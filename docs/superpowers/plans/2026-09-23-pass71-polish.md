## Decisions for this round (final)

- R1 Ctrl-C: a Ctrl-C that interrupts a turn or clears a draft never arms the quit. Quit needs two
  Ctrl-C presses within 1.5 s while idle (the first one shows "Ctrl-C again to quit"). With a live
  run, quitting still asks. The exit summary lists every run it stopped.
- R2 Enter typed before the workspace is ready is kept as a deferred send and replayed once the
  watch is ready (at most one, discarded with a toast if the draft changed or the watch failed).
- R3 The side pane earns its columns: in a conversation whose selected run has one agent and no
  sub-agents it shows a compact run card (state, elapsed, tokens, cost, files changed) and the
  changes list, never the per-step "thinking" operations; the full hive pane stays for swarms and
  workflows. Rails become thin (`▏`-weight or a 1-cell gap with the `border` role), not `▌` blocks.
- R4 Code blocks sit on the `card` surface with a one-row header (language chip left, `y copy` hint
  right in select mode). Inline code keeps its chip.
- R5 Edits show their first hunk inline (at most 12 lines, `+N −M` in the row); longer diffs end
  with "… N more lines · Enter opens". Selecting the row still opens the pager.
- R6 Light mode: when the desktop settings say `mode: light` (or `SWARM_THEME=light`), the TUI uses
  the Carbon light tokens from `~/dev/swarm-code/assets/css/themes.css`; the default stays the
  terminal background with dark roles.
