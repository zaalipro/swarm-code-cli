## apps/swarm_code_cli/lib/swarm_code_cli/release/persisted_session.ex (S1, S1-13)

`TerminalPreferences.launch(env, cli_snapshot, desktop_mode, flags)` is in U3's branch
(`REL/terminal_preferences.ex`). Shape as §3.8.4 plus one additive key, `warnings: [String.t()]`
(e.g. forcing rich glyphs under wide ambiguous width). Wire it as:

```elixir
prefs = SwarmCodeCLI.Release.TerminalPreferences.launch(System.get_env(), CliFile.read_all(path), settings_mode(), flags)
if function_exported?(SwarmCodeCLI.UI.Theme, :put_accent, 1), do: SwarmCodeCLI.UI.Theme.put_accent(prefs.accent)
caps = %Capabilities{..., color_mode: prefs.color_mode, ascii?: prefs.ascii?, glyph_tier: prefs.glyph_tier,
                     ambiguous_width: prefs.ambiguous_width, reduced_motion?: prefs.reduced_motion?}
init = struct(init, prefs: prefs.prefs, theme_mode: prefs.theme, theme_env: prefs.theme_env, mouse?: prefs.mouse?,
              keymap: prefs.keymap,
              launch_facts: %{env_overrides: prefs.env_overrides, flag_overrides: prefs.flag_overrides,
                              flags: flags, project_root: root, log_path: log, cli_path: path,
                              cli_version: vsn})
```

`flags` is keyed by the flag's spelling: `%{"--new" => ""}`, `%{"--continue" => ""}`,
`%{"--resume" => id}` (the launcher script turns the flags into `SWARM_CONVERSATION`, so `%{}` is
also correct; the env layer then reports them). `prefs.companion?` replaces the inline
`System.get_env("SWARM_COMPANION") != "0"`; `prefs.startup_conversation` (`:latest | :new | :ask`)
is the cli.json default when neither a flag nor `SWARM_CONVERSATION` chose.

Why: §3.8.4 (U3 computes, S1 wires).

## U1: `UI/settings/provenance.ex` (env layers)

`launch_facts.env_overrides[key]` may carry `ignored: true, note: "…"` (D40:
`SWARM_KEYMAP=emacs`, `SWARM_THEME=blue`, `SWARM_CONVERSATION=<uuid>`, `SWARM_MOUSE=maybe`) and
`flag_overrides[key]` likewise (`--resume <id>`). Please emit those as ignored layers (never the

`C → E D` (the file wins): place it by the entry's `layers` order.

## U1: `UI/settings/*` ops (additive)

1. `{:edit, row_id, opts}`: open the row's editor with `opts` merged into its editor opts.
   KeysInput's `+` (add a key) opens the capture editor with `%{add?: true}`.
2. `{:project, project_id}`: set `layer.page_project_id` (Approvals & trust's *other projects*
   rows switch the page's project with Enter).
3. `{:cli_write, %{}}` (empty change set) = `CliFile.write_changes(path, %{}, %{})`, the
   "Make it private" rewrite of Files & environment (§3.8.1 last bullet).
4. `{:external_edit, %{ref: "cli.json", …}}`: the return goes through
   `{:settings_cli_write_text, generation, ref, text, fingerprint}` (§2.21, §3.8.2).
5. A nil commit on a nullable `:cli` entry (`terminal.accent`, `terminal.editor`) means
   `:remove` (absent = the default).
