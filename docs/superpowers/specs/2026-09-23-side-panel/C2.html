Story river, v2: every agent still carries its own river, a 12-cell activity lane built from the operations the engine already stores (▂ think, ▅ tools, █ write, ▒ waiting on you, blank idle). It now rolls over the last 60 seconds, so there is no shared axis or orange "now" line, and the lanes stack into one quiet grey column at the right of the panel. The only lanes that glow are the amber ▒ cells of an agent waiting on you, and a flat ▂▂▂ row shows a stalled agent at a glance. Each agent takes 2 rows: glyph, name, lane and state word, then one human sentence with elapsed time and tokens (or, once it is done, its finding). Anything that needs you moves out of the old bottom dock into one amber band pinned under the run header. It quotes the literal request and ends with ^N. The in-chat run gets an accent ▌ and the words "in chat". Each mode bends the river its own way: workflow phases with their steps, goal tries with a judge row, a plan spine with a locked gate, a research funnel, a consensus braid. The whole life of an agent, with story brackets, lives only in its full-screen overlay.

Ctrl-F, or Ctrl-Space where the terminal delivers it, turns on hint mode. The lanes dim, the needs-you band stays lit, and a 3-cell badge sits in front of each state glyph (the glyph stays). Agents that need you get the first letters, then s d f g h j k l, then w e r t u i o p. Past 16 agents the labels become two letters (sa sd …). Badges never use y a Y A d D n q or ?. Digits 1-9 pick runs and 0 opens the runs dashboard. Pressing Ctrl-F again does the same as Ctrl-N (open the next thing waiting on you). Esc cancels. Hint mode never answers anything. Answers use the existing grammar, and only where the request is on screen and the composer is empty: y or a allow once, Y allows for this run, A always allows the command family, d denies, D denies and stops, n moves to the next item waiting. Overlay: Esc returns to the same chat scroll position and draft. [ and ] step through agents in panel order and wrap round. Tab moves focus between band, activity and composer. Enter expands a group, o shows the raw steps, and Enter in the composer steers only this agent. Ctrl-B cycles full → compact → hidden, /panel full|compact|off sets the mode and remembers it. Under 120 columns Ctrl-B cycles strip → off. ASCII twins: states * ~ . ! v x o. Runs * S C * # /. The lane stays readable without colour, because ▂ ▅ █ ▒ differ in height and fill.
