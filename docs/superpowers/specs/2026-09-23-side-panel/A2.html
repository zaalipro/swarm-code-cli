Mission control, honest instruments. The panel is a status board, not a log: every agent is one channel of two rows. The first row is the instrument line: state glyph, name, a 12-cell activity trace (the last 60 s, drawn from stored operations: ▂ thinking, ▅ tools, █ writing, ▒ waiting on you) and elapsed · tokens. The second row says the state word and one plain sentence with a verb, or the finding (» …) once it is done. One amber master-caution band under the header carries the literal request (the command, the file or the question) with ^N to answer it; when nothing waits it is gone. The run the chat shows gets the accent ▌ and the words "in chat". Gauges appear only for known ratios (reviewers reported, phases, iterations, criteria, sources, context). Compact is a flight-strip table (one row per agent: glyph, short name, 8-cell trace, a verb phrase, time), so five runs and 16 agents fit in 30 rows. The agent overlay keeps A's voice: the band on top with the real approval grammar, the whole-life trace with story brackets, the brief and numbered findings with file:line, activity grouped and quoted, and a composer that steers only that agent.

Ctrl-F (or Ctrl-Space where the terminal delivers it) shows hint badges before each state glyph, and the glyph stays. Agents that need you get the first letters, then s f g h j k l, then w e r t u i o p, then c v b m. The letters y a d n q are never used. Digits 1-9 pick a run in panel order, and 0 opens the runs dashboard. Pressing Ctrl-F again is the same as Ctrl-N (the next thing that needs you). Esc cancels. Hint mode never answers approvals. Answers happen only where the request is visible (the transcript card or the overlay band) and only while the composer is empty, using the existing grammar: y or a once, Y this run, A always this command family, d deny, D deny and stop, n next. The overlay keys: Esc goes back to the exact chat scroll and draft, [ and ] step to the previous or next agent in panel order and wrap, Tab moves focus between band, activity and composer, Enter expands a group or sends a steer to this agent only, and o shows the raw operations. Ctrl-B cycles full, compact and hidden (under 120 columns: strip and off). /panel full|compact|off sets the mode, and the choice persists. Ctrl-F now takes forward-char from the composer; that goes in the keymap table.
