Constellation, v2. Each run is still drawn as its own shape: a tree under the Lead for a swarm, a pipeline with parallel steps hanging from the live phase for a workflow, rails converging on a judge for consensus, a shrinking funnel for research, and a checklist spine for goal and plan. Every agent on a shape is now two quiet rows. The first says who it is, its state as a glyph and a word, and its time and tokens. The second is a 60-second pulse built from the operations it has stored (▂ thinking, ▅ tools, █ writing, ▒ waiting on you) followed by one human sentence. When the agent is done, that row becomes its finding plus the evidence behind it. What needs you is no longer just a count: the request itself sits in one amber band under the header. The run the chat is showing has an orange ▌ and the words "in chat" in every view. The panel has no ETA, no per-agent percentages, no legend and no operations. Those details live in the agent overlay: a lane covering the agent's whole life with story brackets, its brief and its own words, activity grouped by kind with one quoted thought, numbered findings with file:line (or the diff, for a writer), and a composer that steers only that agent.

Ctrl-F, or Ctrl-Space where the terminal delivers it, shows hint badges. Each badge sits before an agent's state glyph (the glyph stays), and every run gets a digit. Agents that need you get the first letters, then s f g h j k l, then w e r t u i o p, then c v m. The letters y a d n q are never used. A letter opens that agent's overlay, 1 to 9 scroll the chat to a run and unfold it, and 0 opens the runs dashboard. Pressing Ctrl-F again is the same as Ctrl-N, and Esc cancels. Hint mode never answers an approval. Ctrl-N, which is already bound, goes to the next approval or question waiting on you; every needs-you surface says ^N. You can answer only where the request is visible and while the composer is empty, using the existing keys: y or a allow once, Y allows for this run, A always allows this command family, d denies, D denies and stops the run, and n moves to the next request. In the overlay: Esc goes back to the chat at the same scroll position, with your draft intact. [ and ] step to the previous and next agent in panel order and wrap around. Tab moves focus between the band, the activity and the composer. Enter expands a group or opens the diff or the file, and o shows every raw operation. Enter in the composer steers only this agent. Ctrl-B cycles full, compact and hidden; under 120 columns it cycles the one-row strip and off. /panel full|compact|off sets the mode, and the choice persists. Taking Ctrl-F removes the composer's Emacs forward-char, and the keymap table records that.
