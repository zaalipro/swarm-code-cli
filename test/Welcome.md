# Welcome

This folder is a ZenNotes vault: every note is a plain Markdown file.

- [ ] Press `Space` in `zn tui` to see every command
- [ ] `Space d` opens today's daily note
- [ ] `Space x` lists your tasks, `Space k` shows them as a board

Link notes with [[wikilinks]], tag them with #tags, and add `due:2026-01-31` or `!high` to a task line.
